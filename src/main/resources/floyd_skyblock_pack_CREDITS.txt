The fallback retains 697 additional Hypixel namespace resources from Floyd's previous
bundled legacy pack, originally from https://github.com/nightlibra/hypixel_skyblock_legacy.
Existing upstream resources always take precedence. The additional files include the
Salty Sprayonator and nozzle definitions and their head textures. Two critter capsule
definitions use their provided head-rendering branches because the old legacy bundle
referenced optional model variants that it did not include.

Known items use the pinned upstream item mapping. Unknown items retain their original
Hypixel model and complete textures, following Noamm's resolver. Do not generate paper
placeholders or derive item-model IDs from generic model parents.

Every cached/downloaded server pack is supplemented with missing bundled asset files
before mounting. Existing live files and pack metadata take precedence. A companion ZIP
allows this to work while the original cached ZIP remains open during resource reloads.
